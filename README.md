# Number Guessing Game (C++) 🎮

This is not just a simple number guessing game. As I mentioned in the repository description, my main purpose with this project is learning modern C++ project templates (`src`, `lib`, `doc`, `include`), working with `CMakeLists.txt`, and revising my old coding knowledge.

I am shifting my focus from just "writing code" to "building structured projects."

## 🏗️ Project Structure
I built this project using a standard C++ directory structure to practice multi-file compilation:

* `src/` : Contains the main application and function files (`main.cpp`, `funct.cpp`).
* `include/` : Contains the header files (`kutuphane.h`).
* `CMakeLists.txt` : The configuration file for building the project.

## 🛠️ Tech Stack
* **Language:** C++
* **Build System:** CMake
* **IDE:** Visual Studio

## 💡 Developer's Note
You might find some typos or funny variable names inside the code (like "dumb posibilities"). I decided to keep them as they are! They represent my authentic learning journey as a student. Every small step and atomic habit is building a stronger foundation for the future.

## 🚀 How to Run
If you want to try it out, you can build this project using CMake:
1. Clone the repository.
2. Open the folder in an IDE that supports CMake (like Visual Studio or VS Code).
3. Configure the CMake cache and build the project.
4. Run the executable and try to guess the secret number!
